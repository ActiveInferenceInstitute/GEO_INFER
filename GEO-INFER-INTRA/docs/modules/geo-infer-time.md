# GEO-INFER-TIME

TIME provides strict UTC time series, temporal analysis/forecasting components,
explicit inference schedules, bounded streaming transports, and window processing.
Behavior is owned by `GEO-INFER-TIME/src/geo_infer_time/`; the package exposes
Python interfaces rather than an HTTP server.

## UTC identity and numerical analysis

`normalize_timestamp` uses the standard library for aware scalar datetimes/ISO
strings. `normalize_datetime_index` preserves pandas precision and requires unique,
increasing UTC instants. `TimeSeries` never guesses a timezone, creates epoch times
from an integer index, sorts observations, or imputes missing values.

```python
import numpy as np
import pandas as pd
from geo_infer_time import TimeSeries, TemporalAnalyzer

values = -5.0 + 0.25 * np.arange(8)
series = TimeSeries(values, timestamps=pd.date_range("2024-01-01", periods=8, tz="UTC"))
result = TemporalAnalyzer().detect_trend(series)
assert result["trend_direction"] == "increasing"
assert np.isclose(result["slope_per_sample"], 0.25)
assert np.isclose(result["r_squared"], 1.0)
```

## Public components and composition

Public exports include `TimeSeries`, `TemporalAnalyzer`, `ForecastingEngine`,
`AdvancedForecastingEngine`, `TemporalInterpolator`, `TemporalStatistics`,
`TemporalVisualization`, `EventDetector`, `StreamProcessor`, and transport adapters
such as `ReplayIngestAdapter`. Root/core imports resolve analytical components
lazily; accessing one loads its owning implementation and propagates import errors.

The linear analyzer distinguishes numerical constants from directional slopes and
returns slope per observation and R². Decomposition requires a declared or
unambiguously inferred seasonal sample period. Forecast methods have different
assumptions; inspect the specific method and evaluate out-of-sample behavior rather
than inferring confidence intervals from a point forecast.

`inference_schedule` enforces physical model steps. `action_observation_schedule`
handles observation gaps only with explicit action histories. SPACE owns
`align_h3_observations`, which returns TIME series with declared cell/time axes.
Missing pairs remain NaN; models must choose an observed-data mask explicitly.

## Verification

From the repository root, run
`uv run --no-sync python GEO-INFER-TEST/run_unified_tests.py --module TIME`.
The module regressions verify UTC/DST/nanosecond identity, constructor failure
boundaries, schedules, real IO, streaming cleanup, and independent numerical trends.
