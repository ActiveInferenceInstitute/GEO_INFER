## GEO-INFER-GIT — Geospatial Repository Cloning and Management

GEO-INFER-GIT provides version control and repository management tools specifically designed for geospatial data and code collaboration (module README). In practice it is the framework's repository-integration utility: cloning GitHub repositories by user and configuration, analyzing their structure, and coordinating distributed work. It belongs to the Infrastructure & Validation theme alongside INTRA, TEST, LOG, and EXAMPLES.

The `geo_infer_git` package is organized into `core`, `api`, `config`, and `utils` subpackages with a `cli.py` and `main.py` entry points. The root package exposes runtime metadata; import operations from their owning submodules. `core.repo_cloner` supplies `RepoCloner` with `CloneProgress`, `core.repo_manager` supplies `RepoManager`, and `core.repo_analyzer` supplies `RepositoryAnalyzer`. `core.github_api` supplies `GitHubAPI`, `GitHubRepository` and `RateLimit`; `advanced_git.py` and `multi_platform_api.py` implement extended operations and non-GitHub hosts. The API layer wraps this in a REST service: `rest_api.py` defines Pydantic request/response models (`RepositoryRequest`, `CloneRequest`, `SyncRequest`, `BranchRequest` and their responses) behind an `ErrorHandlerMiddleware`, so cloning and syncing are callable over HTTP as well as CLI.

The unit and integration tests exercise repository operations, rate limits, and service boundaries. Local fixtures and constructed remote responses do not establish access to a live hosted repository.
