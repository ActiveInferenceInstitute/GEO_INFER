## 5. Working rules that kept this green

- Lint/format only through the root Ruff contract; never add per-module tool config.
- Hard dependencies are imported plainly; `try/except ImportError` only for
  extras (`python3` inventory: AST-scan `src/` for Try nodes whose body imports
  a root listed in that module's `[project.dependencies]` — must be 0).
- Randomness: thread a Generator from `utils/rng.py`; no global `np.random` in `src/`.
- Timestamps: timezone-aware UTC at every boundary.
- After changing tracked files, exports or tests: `uv run python GEO-INFER-TEST/rewrite_readme_agents.py`
  and commit the regenerated README/AGENTS together with the change.
- `validate_test_contracts.py --strict` forbids skip/xfail/importorskip text in tests.
