## GEO-INFER-INTRA — Reproducible Documentation Previews

GEO-INFER-INTRA provides reproducible documentation previews and configuration utilities for the GEO-INFER ecosystem (module README). It sits in the Infrastructure & Validation theme: INTRA is how the framework's documentation keeps pace with its modules — generating per-module preview artifacts deterministically rather than by hand.

The `geo_infer_intra` package exports a compact, purposeful surface from `src/geo_infer_intra/__init__.py`: `MODULE_PROFILES`, the configuration table describing every module in the fleet; `SpatialPreviewArtifacts`, the artifact container; the two generation entry points `generate_module_preview_suite` and `generate_all_module_previews`; and three renderers — `render_leaflet_html` for interactive maps, `render_png_card` for raster preview cards, and `render_svg_card` for vector ones. The design is a profile-driven pipeline: profiles declare what each module needs previewed, the generators walk the fleet, and the renderers emit format-specific artifacts. The `assessment_results/` directory records generated outcomes alongside the code that produced them.

The tests exercise documentation previews, configuration, and cross-module system behavior. Preview manifests bind geometry provenance and artifact hashes, while local HTTP and storage integration scenarios exercise actual interfaces. Illustrative preview values are not field observations.
