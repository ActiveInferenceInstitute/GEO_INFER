## GEO-INFER-MATH — Mathematical and Statistical Engine

GEO-INFER-MATH provides geometric operations, spatial statistics, interpolation, optimization, and numerical helpers. Its package `geo_infer_math` organizes `api/`, `core/`, `integration/`, `models/`, and `utils/`.

The public interface, verified from `__init__.py`, spans four clusters. Spatial statistics: `SpatialDescriptiveStats`, `MoranI`, `GearysC`, `GetisOrd`/`getis_ord_g`, `ripley_k`, `semivariogram`, `spatial_entropy`, and `local_indicators_spatial_association`. Interpolation: `SpatialInterpolator` with `IDWInterpolator`, `KrigingInterpolator`, `RBFInterpolator`, `LinearInterpolator`, and `CubicInterpolator` behind an `InterpolationManager` factory. Optimization: `Optimizer` with gradient-descent, genetic-algorithm, SciPy, and multi-objective variants coordinated by `OptimizationManager` and helpers such as `compare_optimization_methods`. Geometry: `Point`, `LineString`, `Polygon`, `haversine_distance`, `vincenty_distance`, `bearing`, and `point_in_polygon`.

The RBF implementation delegates to SciPy's native interpolator with the configured kernel and a finite positive `rbf_epsilon`; distances use the supplied coordinate units. It preserves complex responses, copies training inputs, and leaves an existing fit intact if a refit fails. Native RBF errors propagate instead of silently substituting inverse-distance interpolation. These checks preserve algorithm identity and input ownership; the choice of coordinates, kernel, smoothing, and validation target remains a modeling decision.

The information-theory submodules distinguish channel amplitudes from power gains. MIMO rates use equal independent transmit streams: an explicit total power is divided among transmitters, while the default retains unit power per transmitter. Singular-mode log-rates evaluate the isotropic-covariance expression described by Tse and Viswanath [@tse_wireless_2005, chap. 8], without constructing a Gram matrix or determinant. This does not optimize a channel-dependent transmit covariance. Parallel-channel waterfilling allocates no power to zero-gain channels, and spatial Shannon and Rényi entropy retain the caller's logarithm base. Analytic and constrained-optimization references test these conventions; floating-point conditioning and physical channel assumptions remain study-level limitations.

`geo_infer_math.utils.caching` provides bounded least-recently-used storage and an optional monotonic lifetime. Structured keys retain array shape, dtype, and content; unpickleable arguments bypass storage. Cache state updates are thread-safe, but concurrent misses may compute the same key more than once. Cached values retain native identity, so mutation is shared and caching a computation with effects requires care. Neither cache availability nor a profile establishes a speedup for an unspecified workload.

The tests exercise estimators, native interpolators, cache identity and eviction behavior, and geometric primitives against declared reference values. Individual numerical oracles provide stronger evidence for a named method than the inventory size alone; local analytic fixtures do not establish field predictive accuracy.

Under the declared Module Themes, MATH belongs to Bayesian and active inference. This is an editorial grouping of numerical and inferential responsibilities, not a measured import graph or evidence that every inference module uses every MATH implementation.
