# Cascadia boundary attribution

Cascadia Bioregion Boundary, data analysis by Aquila Flower. [Publisher](https://www.arcgis.com/home/item.html?id=c6497941559d433da98e286fb3f63551).

Publisher license: [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). Retain attribution, the license, and its noncommercial/share-alike conditions when redistributing this data.

The publisher bases this watershed delineation on Cascadia Institute publications, CEC 2011 watersheds and CEC 2010 political/land boundaries. The original delineation used Lambert Azimuthal Equal Area; the hosted layer is Web Mercator and the captured GeoJSON query requests WGS84. Geometry is neither clipped, simplified nor repaired. Serialization and provenance metadata are added; original responses remain intact. Source area attributes retain their original meaning and are not geodesic areas.
