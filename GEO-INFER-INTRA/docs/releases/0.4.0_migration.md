# Migrating to GEO-INFER 0.4.0

0.4.0 is a preparation candidate. A version in package metadata does not establish
published wheels, passing hosted CI, or hardware acceptance. Release evidence is
recorded separately from this migration guide.

## UTC and time axes

TIME owns timestamp normalization. Import `normalize_timestamp` and
`normalize_datetime_index` from `geo_infer_time`. Datetimes and ISO strings need
an explicit timezone. Equivalent offset representations normalize to UTC; two
DST-fold instants remain distinct. NaT, numeric epochs, duplicate model instants,
and reversed model axes fail instead of acquiring an assumed timezone.

If a source deliberately supplies local civil time, localize it at the acquisition
boundary with its actual timezone and an explicit DST ambiguity policy. For
example, `local_index.tz_localize("America/Los_Angeles", ambiguous="raise",
nonexistent="raise").tz_convert("UTC")`. Do not use `replace(tzinfo=...)` on an
already aware value. Use `series.index` rather than `series.index.values`; the
latter erases timezone information.

```python
from datetime import datetime, timezone
from geo_infer_time import normalize_timestamp

assert normalize_timestamp("2026-10-01T02:00:00+02:00") == datetime(
    2026, 10, 1, tzinfo=timezone.utc
)
```

`TimeSeries` requires a unique, increasing aware time axis. Streaming APIs retain
their declared arrival-order policies. Inference schedules still require explicit
fixed model steps or explicit action histories across observation gaps.

Forecasts require complete, finite, regularly sampled univariate data. Select a
column explicitly; missing observations are not silently dropped. Seasonal periods
count samples and must fit the actual cadence. `AdvancedForecastingEngine` accepts
only `arima_fit_kwargs`, `smoothing_fit_kwargs`, and `seasonal_period`; previously
ignored keys now fail. Sum resampling preserves empty/all-missing bins as NaN.
Numeric stream timestamps require an explicit `timestamp_unit` (`s` or `ms`),
replacing magnitude guessing. Plotting requires TIME's `visualization` extra.
See [TIME method contracts](../../../../GEO-INFER-TIME/docs/method_contracts.md)
for numerical units, missing-data behavior, work budgets, and transport deadlines.

## H3 composition

Import `H3StateSpace` and `align_h3_observations` from `geo_infer_space`. The adapter
returns a TIME series with the caller's UTC row axis and exactly the caller's
`state_space.cells` column order. Missing observations remain NaN and observed
zero remains zero. Unknown cells/times, mixed resolutions, duplicate normalized
observations, nonfinite observed values, and allocation-budget violations raise.

Use the same state order for BAYES centroid coordinates and ACT sparse transition
operators. Centroid coordinates are `(latitude, longitude)` in H3 APIs; convert
explicitly for APIs taking `(longitude, latitude)`. Temporal covariates should
carry elapsed seconds, with a declared origin and scale.

SPACE's `kriging_spatiotemporal` was removed. Use
`interpolate_spatiotemporal`; the implementation performs weighted interpolation.
Kriging method labels are no longer accepted by that operation. Unsupported H3
topology operations raise instead of substituting same-cell-only adjacency.

H3 cell identity and geometry are immutable after construction. Grid membership
changes through `add_cell` and `remove_cell`; `H3Grid.cells` is a read-only tuple.
Native neighborhood, child, and uncompact expansion APIs enforce allocation
budgets. Nearest-neighbor statistical inference requires an explicit metric study
area instead of deriving density from an unrelated H3 cover. See
[SPACE method contracts](../../../../GEO-INFER-SPACE/docs/METHOD_CONTRACTS.md)
for configuration precedence, geographic/projected CRS, and topology semantics.
Grid exports own their property data, and earlier membership snapshots remain
stable after adding or removing cells. Native file processing preserves polygon
holes, converts a declared projected CRS to WGS84, and maps points to their exact
H3 cell. Invalid geometry, identities, or cache files raise. Use
`run_analysis(use_cache=False)` to refresh a valid existing cache; cache writes
replace the prior file atomically only after the replacement succeeds.
Grid bounds use cell boundary vertices; longitude extrema can span most of the
world for a cell crossing the antimeridian. They are conventional bounds, not
an inferred minimal wrapped interval.

Spatial statistics reject mismatched observations and propagate topology
failures. Getis-Ord scores that have zero variance or a neighborhood covering the
entire domain return `None` with a per-cell `undefined` reason. Variance-to-mean
ratios with too few observations or zero mean likewise report undefined values;
fractional intensities receive descriptive ratios without a Poisson reference
test. Quadrat counts include observed parent quadrats and do not invent missing
quadrats as zeros.

PLACE temporal methods now use TIME when an explicit `timestamps` axis is
provided. The axis is validated before execution and invalid inputs cannot select
a fallback backend. Value-only sequence statistics retain their local backend;
they cannot provide physical-time claims. `detect_anomalies` and `forecast` accept
`timestamps` as a keyword argument. Trend fit quality is calculated from actual
observed and fitted values rather than interpreting slope magnitude as R-squared.

## Optional integrations and persisted algorithms

DATA declares PostgreSQL, S3, MinIO, Redis, and raster dependencies as separate
extras. An operation requiring an absent extra raises a targeted dependency
error. R-tree indexing remains in the base package. Provision DuckDB Spatial
explicitly with `uv run python GEO-INFER-DATA/provision_duckdb_spatial.py` before
using `read_cloud_native_vector(..., require_duckdb=True)`; this mode propagates
backend errors. Automatic readers load installed extensions without downloading
them and route unsupported layer/reader options through GeoPandas. IOT visualization belongs to
its `visualization` extra and loads when requested. Timestamp fields throughout
DATA and IOT use TIME's explicit UTC normalization.

DATA temporal aggregation, indexing, and storage filters validate original
observation instants before pandas conversion. Repeated observation times and
arrival order remain valid; temporal indexing sorts UTC instants stably rather
than sorting offset strings. Query intervals must be aware and ordered, including
queries against empty stores. Nanosecond precision and input ownership are retained.

ART algorithm persistence uses schema-versioned JSON metadata and registry keys.
Register callables directly or supply an explicitly trusted `algorithm_registry`
mapping. Loading resolves only builtin keys and the caller's mapping; it does not
import or execute code from files. Legacy source-bearing JSON is rejected. Migrate
such files by inspecting the original source yourself, registering trusted
callables, and writing a new registry-based file. The entire incoming file is
validated before registration changes.

## Renamed metrics and exceptions

AI `GeospatialModelEvaluator.evaluate_spatial_accuracy` was removed. Call
`evaluate_value_tolerance(y_true, y_pred, tolerance=...)`; tolerance is measured in
target-value units. The result contains `mean_absolute_error`,
`median_absolute_error`, `max_absolute_error`, `absolute_error_std`, and
`within_tolerance_percentage`. Coordinates and `buffer_distance` are no longer
arguments to this value metric.

MATH's custom `MemoryError` was renamed `MemoryConstraintError`; import it from
`geo_infer_math.utils`. Python's builtin `MemoryError` retains its normal meaning.
MATH imports no longer probe GPU runtimes. Calling a GPU API initializes the
accelerator singleton and performs capability detection.

## Cascadia and verification

Cascadia's reusable implementation is installed inside
`geo_infer_place.locations.cascadia`. Imports from the generic `src` package are
removed. Location configuration and data remain under
`GEO-INFER-PLACE/locations/cascadia`; command scripts delegate to PLACE. Install
PLACE's `cascadia` extra through the root uv workspace. There is no separate
Cascadia distribution, lockfile, or local toolchain configuration.

`EnhancedConfigManager()` reads immutable packaged defaults without creating a
directory in the current working directory. Pass an explicit `config_dir` to
persist configuration updates; an invalid update cannot modify the active state.

The ACT comprehensive audit bundle is generated output. Reproduce it with
`uv run python GEO-INFER-ACT/verify_comprehensive.py --output-dir output/act_audit`.
JSON artifact references are relative to their containing report; generated
artifacts belong under ignored output, not in source control.

The canonical execution APIs live in `geo_infer_test`. Each execution attempt has
its own logs, JUnit and receipt; assertion failures are not automatically retried.
Unknown modules, invalid deadlines, entirely empty lanes, stale/missing/malformed
JUnit, and zero-test reports fail. Backend behavior requires a declared profile
with its dependencies installed; absence tests are separate from behavior tests.
The root remains a virtual uv workspace, and mypy uses the root configuration
explicitly: `uv run mypy --config-file pyproject.toml ...`.

Shared execution owns subprocess descendants that retain the launch environment.
It uses bounded cleanup and retains diagnostics for failures and interruptions.
Captured diagnostics use UTF-8 with replacement for invalid text bytes.
Deliberately hostile children that erase process ownership are outside this test
harness's containment contract.

## Numerical backends and independent spatial scoring

LOG supply-chain optimization solves the declared linear or mixed-integer model
with SciPy HiGHS, preserving objective constants, constraint senses, variable
bounds and integrality. Infeasible models raise; heuristic assignments cannot
stand in for a successful optimization result.

ACT `infer_over_h3_grid` scores each cell from the same initial agent state. It
restores beliefs, policies, histories, random state, and the configured analyzer;
changing cell iteration order cannot change a cell's posterior. Grid scoring
does not append interaction records to an analyzer's output directory.
The aggregate grid diagnostic is the mean of the observed cell free energies.
`NestedH3LevelSummary.mean_free_energy` was removed; use
`mean_reference_kl_to_uniform` for that level's posterior-versus-uniform reference
score. Factored summaries report entropy from the declared or retained joint
distribution, preserving factor dependence.

Flat categorical `ActiveInferenceModel.step` conditions a real observation and
selects an action; advancing time requires `predict_beliefs(action_index)` with
one declared action per interval. Factored domain models have their own explicit
next-prior propagation. Unsupported model names/configurations raise.

ANT's `SwarmAgent` defaults to its rule policy. Enabling ACT requires a configured
flat categorical model, an observation encoder, and action dictionaries ordered
like its transition axis. Execute the selected action before another decision.
Successful execution advances the prior once and records prediction history;
failed execution leaves it unchanged. Encoder/model failures propagate, and
expected outcomes never become fabricated observations.
The selected transition uses an owned physical-action snapshot. Mutating the
returned decision cannot retarget execution, and concurrent execution of the
same decision raises. If prediction fails after a successful physical action,
retrying that decision retries propagation without repeating the physical work.

RISK consumes the public `TemporalAnalyzer`, `ForecastingEngine`, and `TimeSeries`
interfaces. Temporal records need explicit aware `timestamp` and numeric `value`
fields. Trend units are value per sample; forecast horizons count model steps,
and monthly grouping uses the UTC calendar. Invalid temporal inputs fail the
analysis instead of producing a fallback result.
An installed integration's import or constructor failure propagates; it cannot
turn into an availability fallback. RISK retains each validated SPACE/TIME
interface rather than constructing a separate unverified instance afterward.

ACT's Gaussian free energy and ELBO now use covariance/precision determinants and
traces consistently. Dynamic causal inference uses actual elapsed-time derivative
fits. Climate/ecological factor observations update real factor posteriors.
Urban planning evaluates the declared bounded horizon; its default is two steps.
These corrections can change numerical results from earlier versions.
Generic Gaussian `ActiveInferenceModel.act` now raises because that interface
does not declare control dynamics. Use `ContinuousPOMDPActiveInference` or the
Gaussian GNN runner for explicit continuous controls. Gaussian measurement free
energy respects the configured observation map, including rectangular maps.

`GenerativeModel.integrate_bayeux` selects `numpy_metropolis` explicitly by default;
choose `backend="bayeux"` for real NumPyro NUTS. The `backends` extra bounds flowMC,
JAX, and Optax to the compatible Bayeux API family. Failed samplers propagate
errors and unmeasured ESS/marginal likelihood are not reported as measurements.
RxInfer requires Julia; `backend="local_gaussian"` explicitly selects the local
conjugate scalar model and does not establish Julia acceptance.

SPM defaults to two sampling chains on one worker core. Actual PyMC backend
failures propagate; only a genuinely absent PyMC installation permits the
documented approximation. macOS 27 users affected by PyTensor's obsolete
`-ld64` linker argument can select the explicit, guarded compiler profile in
[native sampling profiles](../../../../GEO-INFER-SPM/docs/native_sampling_profiles.md).
This profile runs the native compiler and preserves compiled sampling.
