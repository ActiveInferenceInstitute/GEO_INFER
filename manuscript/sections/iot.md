## GEO-INFER-IOT — Sensor Networks and Real-Time Geospatial Streams

GEO-INFER-IOT covers IoT sensor networks, real-time geospatial data streams, and sensor data fusion for environmental monitoring (module README). It belongs to the Data, API & Applications theme and is the framework's live-data boundary: where batch spatial analysis meets continuously arriving measurements from deployed sensors.

The `geo_infer_iot` package exports a layered surface from `src/geo_infer_iot/__init__.py`. Core functionality: `IoTDataIngestion`, `SensorRegistry`, `RadiationMonitoringSystem`, and `GlobalMonitoringSystem`. High-level convenience classes: `IoTSystem`, `BayesianSpatialInference`, `MultiModalFusion`, `AdaptiveSampling`, and `PredictiveMaintenance` — notably bridging into the Bayesian & Active Inference theme, since sensor streams feed spatial inference directly. Module components complete the layer: `SpatialDataFusion`, `QualityController`, `SensorAPI`, `StreamingAPI`, and `BayesianInferenceAPI` for services; `Sensor`, `SensorNetwork`, `Measurement`, `MeasurementBatch`, `NetworkTopology`, and `SensorCalibration` as typed domain models; `SpatialInterpolation` and `IoTVisualization` for analysis and display. A `deployment/` directory addresses operational rollout.

The unit and integration tests exercise sensor ingestion, registry mutation, quality control, timestamps, and exact coordinate bounds. Typed measurements can feed spatial fusion and Bayesian inference; local acceptance does not establish hardware delivery or a live sensor deployment.
